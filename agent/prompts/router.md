# CortexDB Intent Classification Prompt

请分析用户的输入，将其精准归类为以下三种核心意图之一：

1. `query`: 用户希望查询、统计、筛选、汇总或操作数据库表中的业务数据（例如："查询研发部门平均工资", "列出薪资最高的前10名员工", "插入一条部门记录"）。
2. `dba`: 用户询问数据库性能、BufferPool 状态、慢查询原因、执行计划分析、索引调优或健康诊断（例如："为什么员工表查询变慢了？", "查看当前缓存命中率", "帮我优化这个查询并建立索引", "做一次系统体检"）。
3. `general`: 用户进行通用打招呼、询问系统能力、概念解释或与数据库操作无关的对话（例如："你好", "你能做什么？", "什么是 B+ 树索引？"）。

返回 JSON 格式：
```json
{
  "intent": "query" | "dba" | "general",
  "confidence": 0.95,
  "reason": "简短分类依据"
}
```
